# Vibe Coding Landing Page

Marketing-style landing page for **vibe coding** — AI-driven development where you describe apps in natural language and launch them locally.

## Launch locally

```bash
cd /Users/dvalia/Development/ClaudeProject-With-AIDLC
chmod +x scripts/launch-vibecoding-landing.sh
./scripts/launch-vibecoding-landing.sh
```

Open **http://localhost:3847**

Alternative:

```bash
cd vibecoding-studio && npm start
```

## What's on the page

- Hero and definition of vibe coding (research-backed)
- How-it-works workflow (describe → generate → launch)
- Feature highlights and 2026 tool ecosystem
- Step-by-step local launch instructions with copy buttons
- Demo project launcher (number guessing game)

## Requirements

- Node.js 18+
- No API keys or database needed
