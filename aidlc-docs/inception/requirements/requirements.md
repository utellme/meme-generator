# Requirements — Number Guessing Game

## Intent Analysis
- **Clarity**: Clear
- **Type**: New Project
- **Scope**: Single File
- **Complexity**: Trivial

## Functional Requirements
1. Generate a random integer between 1 and 100 (inclusive).
2. Accept numeric guesses from the user via stdin.
3. Display each number the user guessed.
4. Provide feedback (too high / too low) until the user guesses correctly.
5. Show total guess count when the game ends.

## Non-Functional Requirements
- CLI-only; no external dependencies.
- Python 3.8+ compatible.
